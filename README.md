# FIRE SHAWARMA — сайт с онлайн-заказом для стрит-фуда в Минске

Готовый коммерческий сайт для шаурмичной: меню на 23 позиции, умная корзина, промокод, скидка за самовывоз, бесплатная доставка и приём заказов сразу в **Telegram** и **Google Таблицу** через серверную функцию Netlify. Без фреймворков и сборки: открыл, задеплоил, работает.

**Живая демо-версия: [fire-shawarma-minsk.netlify.app](https://fire-shawarma-minsk.netlify.app)**

> Проект сделан как витрина для заказчиков (фриланс, студии). Его можно взять за основу для кафе, пекарни, пиццерии или любого заведения с доставкой в Беларуси.

## Что умеет сайт

**Меню и карточки**
- 23 позиции в 6 категориях: шаурма, комбо, пита, закуски, соусы, напитки. Каталог лежит одним массивом `MENU_ITEMS`, карточки рисуются из него.
- Выбор размера прямо на карточке: шаурма S 200 г / M 300 г / L 400 г (у классической ещё XL 500 г). Цена и вес меняются сразу.
- Выбор объёма у лимонада и коктейлей: 0,3 л / 0,5 л.
- Окно настройки блюда: размер, добавки (доп. сыр, халапеньо, двойное мясо, без лука), количество и итоговая цена.
- Бейджи «Новинка», фильтр по категориям с управлением с клавиатуры.

**Корзина и оформление**
- Корзина хранится в `localStorage` и переживает перезагрузку страницы. Одинаковые блюда с одинаковыми опциями объединяются в одну строку.
- Прогресс-бар до бесплатной доставки: от 25 BYN, иначе доставка 3.00 BYN.
- Промокод `MINSK10`: скидка 10% на первый заказ.
- Самовывоз: скидка 10%. Скидки не суммируются: действует либо самовывоз, либо промокод.
- Белорусский телефон: маска `+375 (XX) XXX-XX-XX` и проверка кодов операторов 25, 29, 33, 44.
- Выбор способа оплаты (картой, наличными, по QR), комментарий к заказу, выбор точки самовывоза.
- Экран «Заказ принят!» с номером заказа.

**Заказы и безопасность**
- Форма отправляет заказ в `/.netlify/functions/sendOrder`.
- Функция **пересчитывает цены и скидки на сервере** по собственному каталогу. Подмена цены или размера в браузере не работает: неизвестные позиции, размеры и добавки отклоняются.
- Чек уходит в Telegram-бот, и одновременно JSON уходит в Google Таблицу. Заказ принят, если сработал хотя бы один канал.
- Токены хранятся только в переменных окружения Netlify и не попадают в браузер.

**Интерфейс**
- Спокойный светлый дизайн, шрифты Plus Jakarta Sans и Manrope, терракотовый акцент.
- Адаптивная вёрстка от 320 px, корзина-шторка, нижняя панель корзины на телефоне.
- Доступность: семантическая разметка, фокус-ловушка в окнах, закрытие по Esc, `aria`-атрибуты, поддержка `prefers-reduced-motion`.
- Две точки в Минске (ул. Немига, 5 и пр-т Независимости, 44) со ссылками «Построить маршрут» в Яндекс Картах.

## Запуск и деплой

### 1. Telegram-бот
1. В Telegram откройте `@BotFather`, команда `/newbot`, получите токен бота.
2. Напишите своему боту любое сообщение (или добавьте его в группу и напишите там).
3. Откройте в браузере `https://api.telegram.org/bot` + ваш токен + `/getUpdates` и найдите `"chat":{"id":...}`. Это `TELEGRAM_CHAT_ID`.

### 2. Google Таблица
1. Создайте таблицу на [sheets.new](https://sheets.new).
2. «Расширения» -> «Apps Script», вставьте содержимое файла `google-apps-script.js` и сохраните.
3. «Развернуть» -> «Новое развертывание» -> «Веб-приложение»: выполнять как «Я», доступ «Все».
4. Скопируйте URL веб-приложения. Это `GOOGLE_SHEET_URL`.

Подробная инструкция есть в шапке файла `google-apps-script.js`.

### 3. Netlify
1. Загрузите папку проекта в GitHub и подключите репозиторий в Netlify («Add new site» -> «Import an existing project») или перетащите папку в раздел Deploys.
2. Настройки сборки уже лежат в `netlify.toml`: публикуется корень проекта, функции берутся из `netlify/functions`.
3. В «Site configuration» -> «Environment variables» добавьте три переменные:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от BotFather |
| `TELEGRAM_CHAT_ID` | id чата, куда приходят заказы |
| `GOOGLE_SHEET_URL` | URL веб-приложения Google Apps Script |

4. Запустите новый деплой (Deploys -> Trigger deploy), чтобы функция увидела переменные.

Google Таблица необязательна: если `GOOGLE_SHEET_URL` не задан, заказы уходят только в Telegram, и наоборот.

### Локальный запуск
Статическую часть можно открыть через любой HTTP-сервер. Для проверки заказов вместе с функцией используйте Netlify CLI:

```bash
cp .env.example .env
npx netlify-cli dev
```

Откройте `.env` и впишите значения переменных. Файл `.env` в Git не попадает (он в `.gitignore`).

> Если открыть `index.html` двойным кликом из Finder, меню и корзина работают, но заказ не отправится: серверная функция доступна только на Netlify или через `netlify dev`.

## Как менять под другого заказчика

- **Меню и цены:** массив `MENU_ITEMS` в `app.js` и зеркальный `CATALOG` в `netlify/functions/sendOrder.js`. Цены хранятся в копейках, поэтому правятся в обоих файлах.
- **Промокоды и пороги:** константы `PROMO_CODES`, `FREE_DELIVERY_FROM`, `DELIVERY_FEE` в `app.js` и их копии в `sendOrder.js`.
- **Фото:** файлы `images/N.jpg`, номер указывается в поле `photo` позиции.
- **Цвета и шрифты:** переменные в блоке `:root` файла `style.css`.
- **Точки и контакты:** `index.html`, блоки «Адреса» и подвал.

## Что делает серверная функция

1. Принимает `POST` с составом заказа и данными клиента.
2. Проверяет все поля: имя, белорусский номер, адрес или точку самовывоза, способ оплаты, количество.
3. Считает сумму по своему каталогу, применяет скидку (самовывоз или промокод) и доставку.
4. Формирует чек и отправляет его в Telegram, одновременно передаёт JSON в Google Таблицу.
5. Возвращает номер заказа и итоговую сумму для экрана «Заказ принят!».
